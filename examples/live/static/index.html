和 SenseMem 自然对话

点击「开始通话」，允许使用麦克风和摄像头。试着与它一起经历一件小事。

  1. 让它记住眼前。 展示钥匙放在哪里，在「经历」中查看新记忆与原片。
  2. 让理解随你更新。 在「了解你」中查看来源、纠正理解，或暂时遗忘。历史中可以撤销。
  3. 边说边回忆。 SenseMem 持续听取声音、观察画面并提前检索；s2s 读取这些上下文后生成语音。你可以随时开口打断。

SenseMem 会异步寻找相关经历，将带来源与时间的历史证据送入当前通话。记忆、画面或声音中的有用变化可触发回应；你开口时优先聆听。「记忆已送入通话」表示模型收到证据，回答仍需以原片核对。

字幕显示语音转写与 Agent 回复。你的原始音视频和 Agent 已播放的语音分别保留。首次画面观察与之后的画面变化会异步保存原图，形成可检索的记忆。

麦克风与摄像头 → SenseMem 感知与提前召回 → s2s 读取上下文并回答。s2s 使用 Paraformer 识别、Qwen 回答、Aiden 发声；画面由 SenseMem 处理，不是 s2s 的原生视频输入。

音视频持续保存，记忆在后台理解；停止通话后仍会继续处理。模型推断与原始经历分开呈现，证据不足的推断不会参与召回。

模型配置：examples/live/config.example.json。在启动服务的环境中使用已有的模型凭据；完整说明见 docs/live-demo.md。

音频、抽样画面及片段会交给你配置的模型服务处理。建议佩戴耳机；回放原片时可先静音麦克风。
